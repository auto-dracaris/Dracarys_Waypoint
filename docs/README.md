## Viewing Diagrams

This folder contains diagram files such as `architecture.drawio` and `proposed_mlops_pipeline.drawio`.

**If the diagrams do not render directly in your web browser or repository viewer:**

1. Download the `.drawio` file to your local machine.
2. Open a new tab and navigate to [draw.io](https://app.diagrams.net/) (diagrams.net).
3. Drag and drop the downloaded file directly into the draw.io interface to view or edit the diagram.


* **`architecture.drawio`**: The core system architecture diagram.


* **`proposed_mlops_pipeline.drawio`**: Diagram outlining the proposed MLOps pipeline structure.
