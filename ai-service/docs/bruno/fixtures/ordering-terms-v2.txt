Store ordering terms, test version 2

A store manager should check the requested delivery date, required temperature,
order units, total weight and total volume before placing an order.
Test version 2 also requires checking the outlet contact details.
If an item is deferred, read the recorded reason and updated date in the order.
Drivers should confirm the delivery address before leaving.
Loaders should verify the load details before loading.
Dispatchers should review a document before approving it for assistant use.
